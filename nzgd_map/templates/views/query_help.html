Example Queries

  • (vs30 < 100) & (region=="Canterbury") - Show records where Vs30 is less than 100 m/s and the region is Canterbury
  • type_prefix == "BH" - Show borehole records. The current database uses CPT and BH; SCPT records are included under CPT.
  • record_created_on > "2024-08-20" - Show records created in NZGD after 20 August 2024. This is not the investigation date.
  • spt_id == 31 - Show one SPT report. Report IDs and NZGD record IDs are distinct.

Query Syntax

Filters support the following pandas-style comparisons and column methods:

  • Comparison operators: ==, !=, <, >, <=, >=
  • Logical operators: & (and), | (or), ~ (not)
  • String comparison: column == "value" (exact match), column.str.contains("value") (literal partial match), column.str.contains("value", case=False) (ignore letter case), column.str.startswith("value") and column.str.endswith("value")
  • Numerical ranges: (column > lower_bound) & (column < upper_bound)
  • Membership: region in ["Canterbury", "Auckland"] or region.isin(["Canterbury", "Auckland"])
  • Missing values: extracted_gwl.isna() or extracted_gwl.notna()
  • Numeric operations: vs30_log_residual.abs() > 0.5, vs30.between(200, 400), and arithmetic using +, -, *, /, %

String matches use literal text, not regular expressions. Other Python expressions and methods are not supported.

Vs30 availability and missing values

The “Reports to include” selector applies after your query. “All reports with measurements” keeps reports even when no Vs30 estimate is available for the selected correlations. An available estimate is a finite, positive stored Vs30 value; uncertainty and a model residual are not required.

A query such as vs30 > 200 still excludes missing Vs30 values. Use vs30_available == False to select unavailable estimates explicitly. Histograms omit unavailable values and show how many reports were excluded.

Depths and groundwater levels are in metres; Vs30 values are in metres per second. model_vs30_stddev_foster_2019 is in natural-log units. original_reference is an alias for original_investigation_name. Record creation and modification timestamps are not investigation dates.

Advanced Examples

  • deepest_depth > 20 - Records with depth greater than 20 meters
  • (vs30 > 200) & (vs30 < 400) - Records with Vs30 between 200 and 400 m/s
  • (region=="Canterbury") | (region=="Auckland") - Records from Canterbury OR Auckland regions
  • ~(type_prefix=="BH") - All records EXCEPT boreholes
